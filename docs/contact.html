Contact and privacy

Questions and support

For general or private questions, privacy questions, or deletion requests, email mj.apps.support@gmail.com. You do not need a GitHub account to email.

For public bug reports and feature requests, use GitHub Issues. Issues are public: do not include private information, passwords, or API keys.

This walkthrough and your data

This disclosure covers this recorded static walkthrough, which makes no live API calls and offers no file uploads or product analytics. It does not describe the local iOS app or backend.

Your language and theme choices are saved in this browser's storage. You can remove them by clearing this site's browser data.

GitHub Pages hosts this page. GitHub may process request data such as your IP address under the GitHub General Privacy Statement.

If you choose to contact support, your email address and message go through Gmail so the maintainer can respond. GitHub handles information you submit to Issues, where your report is public. Do not send passwords, API keys, or other credentials through either channel.
